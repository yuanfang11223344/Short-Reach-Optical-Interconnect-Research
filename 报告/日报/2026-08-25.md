## 🔌 SerDes与互连技术

1. 🔥 **NVIDIA Hot Chips 2026 今日进入 BlueField-4、Spectrum-X Multiplane Network Architecture 与 LPU Accelerator 三个互连相关主题。** 官方日程把 DPU、Ethernet fabric 与低延迟推理加速器放在同一天，说明 AI factory 的瓶颈不再只在 GPU，而在数据搬运、网络隔离、collective 与端到端调度。https://www.nvidia.com/en-us/events/hot-chips-conference/
2. 🔥 **OIF current work 已把 CEI-448G-VSR/LR 与 224G PAM4 link training 放进同一标准化队列。** 448G-VSR 面向 chip-to-module，目标覆盖至少 200 mm host channel、20 mm module channel 和连接器；448G-LR 面向 backplane，目标至少 1000 mm 和至少两个连接器。https://www.oiforum.com/technical-work/current-work/
3. ⭐ **OIF CEI-224G-Linear 明确服务 full linear optical modules，并覆盖 LPO、CPO 与 NPO。** 对 AI/ML、UEC 与下一代 Ethernet，低功耗、低成本、低复杂度和低延迟正成为 224G electrical I/O 的共同约束，而不是某一种光模块形态的单点优化。https://www.oiforum.com/technical-work/current-work/
4. ⭐ **Broadcom OFC 2026 组合把 200G/lane Ethernet retimers、AEC、PCIe Gen6 switch/retimer 与 102.4T Ethernet switch 放进同一 AI infrastructure portfolio。** 这说明短距互连正在按 reach 分层：机柜内仍会保留 AEC/retimer，scale-out 和 scale-across 则继续推向 1.6T/3.2T optics 与 CPO/NPO。https://investors.broadcom.com/news-releases/news-release-details/broadcom-showcases-industry-leading-solutions-scaling-ai

## 🔦 光学与光模块

1. 🔥 **OIF 12.8Tb/s NPO Module Project 将 12.8T/6.4T near-package optics 建在 200G/lane signaling 上，并纳入 liquid-cooling thermal interface、laser source、power supply 与 optical connector。** 这把 NPO 从“靠近 ASIC 的光模块”升级为机械、电气、热、光源和连接器共同定义的系统接口。https://www.oiforum.com/technical-work/current-work/
2. 🔥 **OIF COI 项目面向 PCIe、NVLink、UALink 等 AI scale-up links 开发低延迟、低能耗 photonic interfaces。** 这是一条比传统 Ethernet optics 更靠近 accelerator attach 的光互连路线，后续关键在协议训练、时延预算、管理接口和多供应商互操作。https://www.oiforum.com/technical-work/current-work/
3. ⭐ **Broadcom Taurus BCM83640 以 3nm 400G/lane optical PAM4 DSP 支撑 1.6T transceiver，并为 3.2T module 和 204.8T switching platform 铺路。** 其公开材料强调 400G/lane optical interface、1.6T pluggable、未来 3.2T 和 448G/lane transceiver；这会把测试难度从 224G electrical 扩展到 400G/lane optical。https://investors.broadcom.com/news-releases/news-release-details/broadcom-delivers-industrys-first-400glane-optical-dsp-next
4. ⭐ **Marvell 1.6T optical DSP portfolio 已细分为 Ara T、Ara X、Petra、Aquila M 等不同用例，并覆盖 DSP、SerDes、drivers/TIAs、gearbox、telemetry 与 coherent-lite。** 1.6T 市场不再只是“谁先出 DSP”，而是不同链路形态、可靠性、TCO、安全和制造能力的组合竞争。https://investor.marvell.com/news-events/press-releases/detail/1013/marvell-ushers-in-the-1-6t-era-with-expanded-optical-dsp-platform-portfolio-redefining-ai-data-center-end-to-end-connectivity

## 🖥️ AI服务器与超节点

1. 🔥 **NVIDIA Vera Rubin NVL72 官方描述把 72 个 Rubin GPUs、36 个 Vera CPUs、ConnectX-9 SuperNICs 和 BlueField-4 DPUs 组合成 rack-scale platform。** 该平台用第六代 NVLink/NVLink Switch scale up，并以 Quantum-X800 InfiniBand 与 Spectrum-X Ethernet scale out；互连采购需要同时评估 GPU、CPU、NIC、DPU、switch、optics 与软件栈。https://www.nvidia.com/en-us/events/hot-chips-conference/
2. 🔥 **BlueField-4 在 NVIDIA 叙事中承担 AI factory operating system 的基础设施角色。** 官方 BlueField 页面称 BlueField-4 DPU 是 800 Gb/s infrastructure platform，面向 networking、data storage 与 cybersecurity 加速；对 AI supernode 来说，DPU 已从“网卡旁路”变成多租户、存储路径和安全边界的一部分。https://www.nvidia.com/en-us/networking/products/data-processing-unit/
3. ⭐ **NVIDIA Spectrum-X Ethernet Network Architecture 在 Hot Chips 页面被定位为 modern AI workload 的高性能连接层。** 当前重点不是单个交换芯片指标，而是 Ethernet fabric 能否在多租户、拥塞、集体通信和跨站点作业下保持可预测性能。https://www.nvidia.com/en-us/events/hot-chips-conference/
4. ⭐ **UALink 7 月博客列表显示其 2026 年继续围绕 open scale-up connectivity、in-network compute、compliance/interoperability 与 FMS/OCP 活动扩展生态。** 与 UEC scale-out 相比，UALink 的价值在 accelerator-to-accelerator scale-up；后续要看规范版本、测试计划和实际 switch/NIC/IP 支持。https://ualinkconsortium.org/category/blog/

## 🏢 计算中心与基础设施

1. 🔥 **NVIDIA 45°C liquid cooling 设计把 Rubin generation 描述为 100% liquid cooling，覆盖每颗芯片和每个 networking component。** 官方博客称闭环液冷和 dry cooler 可显著降低冷却能耗和用水；对互连系统来说，switch、NIC、DPU 与 optics 的热边界将被纳入整机柜液冷设计。https://blogs.nvidia.com/blog/liquid-cooling-ai-factories/
2. 🔥 **UEC 将在 2026-09-15 至 2026-09-17 AI Infra Summit 展示 Ultra Ethernet，并把活动轨道连接到 Compute、Data Movement 与 AI Data Centers。** 这为 UEC 1.0.3 从规范走向生态验证提供观察窗口，重点应放在 NIC/switch/software interoperability，而不是单个厂商宣传。https://ultraethernet.org/event/uec-at-ai-infra-summit-2026/
3. ⭐ **OIF 1600CL、1600ZR、1600ZR+ 把 AI campus/metro DCI 的接口继续推向 1.6T coherent。** 1600CL 面向更大 data center campus 的 1600G LR optics，目标相对 1600ZR 改善 power efficiency 与 latency；1600ZR/ZR+ 则覆盖 120 km 到更长距离 DCI。https://www.oiforum.com/technical-work/current-work/
4. ⭐ **OIF MACsec Support for 1.6T Pluggable Modules 项目提示 hyperscaler DCI 会把安全能力下沉到 coherent pluggable 数据路径。** 当 AI campus 和多站点训练扩大，链路加密、模块管理和性能监控会和速率、功耗一起成为采购条件。https://www.oiforum.com/technical-work/current-work/

## 📄 论文速递

1. 🔥 **arXiv:2608.11639 — “Towards Terabit/λ/s Multidimensional Silicon Photonic Engine”。** 论文提出 multidimensional silicon photonic engine，声称通信容量超过 1.8 Tb/s/λ/s，并演示 300 m full-duplex inter-chip communication；它的核心价值是用 spatial/polarization 多维复用减少 fiber/connector 压力，但工程化仍需验证封装、温漂、批量一致性和控制复杂度。https://arxiv.org/abs/2608.11639
2. 🔥 **HotI 2026: “Scaling Inference Prefill with High-Radix Photonic Interconnect”。** 该论文题目把 high-radix photonic interconnect 与 LLM inference prefill scaling 直接绑定，值得后续跟踪其拓扑、batching、tail latency 与实际光交换实现。https://hoti.org/2026/program.html
3. ⭐ **HotI 2026: “Breaking Through the Network Wall: Petabit-Class Switching for Single-Hop MoE Training at Scale”。** MoE training 的 all-to-all traffic 会放大 fabric bisection bandwidth 和拥塞控制压力；petabit-class single-hop switching 若能落地，会改变训练网络层级设计。https://hoti.org/2026/program.html
4. ⭐ **HotI 2026: “The Multipath Reliable Connection (MRC) Transport”。** 该题目聚焦 reliable transport 与 multipath，适合与 UEC/UET、RoCE、NCCL/RCCL 和大规模 collective 一起观察。https://hoti.org/2026/program.html
5. 📌 **arXiv:2608.03146 — “Zero-change foundry compatible silicon photonics MEMS optical switch”。** 论文展示 C-band broadband MEMS optical switch，摘要给出 >30 dB extinction ratio、<1.5 dB insertion loss 和约 20 nW static power；它适合作为 OCS 器件路线参考，但离大规模数据中心 OCS 还需要阵列、封装和可靠性验证。https://arxiv.org/abs/2608.03146
