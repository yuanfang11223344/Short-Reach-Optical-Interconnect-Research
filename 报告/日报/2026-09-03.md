## 🔌 SerDes与互连技术

1. 🔥 **OIF Q3 2026 会议后批准 CMIS-LT 与 C-CMIS 1.5，把 host-module link training 与 coherent module management 推进到 Implementation Agreement 层面。** 公告口径称 CMIS-LT 用于 out-of-band host-module link training，C-CMIS 1.5 则推进 400ZR coherent optical module 的 common management；这对 224G/448G electrical interface、linear optics、coherent pluggables 和现场运维软件都是关键基础，不应解读为某个厂商产品已经完成全生态互通。https://uk.finance.yahoo.com/news/oif-closes-q3-member-meeting-131600056.html
2. 🔥 **OIF ECOC 2026 互操作展示继续把 448Gbps signaling、800ZR、CMIS、CPO/NPO 与 EEI 放在同一组演示中。** OIF 页面显示其将在 ECOC 2026 通过多厂商演示覆盖 optical systems、CMIS、co-packaging/near-package optics 与 energy-efficient interfaces；对 AI 网络而言，接口速率、管理面和能效接口正在一起决定可部署性。https://www.oiforum.com/oif-validates-ai-era-interoperability-live-at-ecoc-2026-through-multi-vendor-demonstrations-and-expert-sessions/

4. ⭐ **UALink 最新规格仍是开放 accelerator scale-up fabric 的重点观察对象。** UALink 官网说明新规格面向 multi-workload environments，并改善 AI workload performance、efficiency 与 implementation ease；7 月 30 日 webinar 主题为 "What's New in UALink?"，说明联盟正在围绕最新规格做生态解释和技术教育。https://ualinkconsortium.org/
5. 📌 **UEC 官网继续强调完整 communications stack，而不只是 Ethernet link speed。** UEC 把 multipathing、ease of configuration、management、scale 与 interoperability 放在目标中；与 OIF CMIS-LT 的管理面进展合看，AI Ethernet 的瓶颈正在从单点带宽扩展到链路训练、拥塞控制、遥测和多供应商 bring-up。https://ultraethernet.org/

## 📄 论文速递

1. 🔥 **arXiv:2608.15118 - "Collective Communication for Distributed LLM Systems: Planning, Runtime Adaptation, and Computation Coordination"。** 论文把 LLM training/serving 的 collective communication 分为 planning、execution/adaptation、computation-communication coordination 三层；对 AI fabric 评估，重点是 topology-aware schedule、multi-NIC、heterogeneous interconnect 与 end-to-end iteration time 的关系。https://arxiv.org/abs/2608.15118
2. 🔥 **arXiv:2602.12521 - "Photonic Rails in ML Datacenters with Opus"。** 论文提出用 optical circuit switches 实现 rail-optimized network fabric，并在 parallelism phase boundaries 做 reconfiguration；作者报告在 production-relevant OCS reconfiguration latencies 下可显著降低网络功耗和成本，但这是研究评估，不等于通用商业部署结论。https://arxiv.org/abs/2602.12521
3. ⭐ **arXiv:2603.07373 - "Scheduling Parallel Optical Circuit Switches for AI Training"。** Spectra algorithm 将 AI traffic demand matrix 分解成 weighted permutations，并在多个 parallel OCS 与 reconfiguration delay 约束下调度；这类工作把 OCS 从硬件可行性推进到 workload-aware scheduling。https://arxiv.org/abs/2603.07373
4. ⭐ **arXiv:2608.03146 - "Zero-change foundry compatible silicon photonics MEMS optical switch"。** 论文展示 C-band broadband silicon photonics MEMS switch，强调 zero-change foundry-compatible process 与 BEOL post-processing；其意义在于为大规模、低功耗、可编程 optical circuit switch 提供器件路径。https://arxiv.org/abs/2608.03146
5. 📌 **arXiv:2603.21313 - "3D optoelectronics and co-packaged optics: when solving the wrong problems stalls deployment"。** 论文提醒 CPO 的关键挑战不只是光电器件指标，还包括 packaging、thermal management、serviceability 与 system robustness；这与 OIF/ECOC 对 CPO/NPO 管理和互操作的关注一致。https://arxiv.org/abs/2603.21313
