## 🔌 SerDes与互连技术

1. 🔥 **ECOC 2026 后，224G/448G electrical I/O 的主线从“能跑多快”转向“能否跨 host、module、cable 与 test platform 稳定互操作”。** OIF 官方公告称 39 家成员公司参与 ECOC 2026 互操作演示，覆盖 CEI-448G/224G、Common Management Interface Specification、Co-Packaging、Energy Efficient Interfaces 和 coherent optics；这类 demo 的价值在于把 lane rate、管理接口和封装边界放到同一验证场景。https://www.oiforum.com/oif-brings-industry-wide-interoperability-to-life-at-ecoc-2026-accelerating-scalable-efficient-networks-for-the-ai-era/
2. 🔥 **Ethernet Alliance 的 1.6T ECOC demo 把 224G SerDes link training、800G AI lossless link 和 1.6T OSFP connectivity 连接起来，说明 AI fabric 的问题已经跨越 PHY、PCS、flow control 和 congestion management。** 官方博客列出 400G、800G、1.6T Ethernet 展示，以及 LLR、CBFC 等 lossless Ethernet 机制；对 AI 集群而言，稳定性和可调试性正成为与端口速率同级的指标。https://ethernetalliance.org/blog/2026/09/09/1-6t-ethernet-moves-closer-to-reality-in-ethernet-alliances-ecoc-2026-demo/
3. 🔥 **Marvell 继续用 2nm optical interconnect demo 强调 400G/lane PAM4、1.6T coherent-lite 和 102.4T CPO 的同平台路线。** 公司新闻把 400G per lane PAM4 electrical I/O、800G ZR/ZR+ with MACsec、1.6T ZR/coherent-lite 和 102.4T CPO 归入 AI data center infrastructure portfolio；这仍是官方展示和产品路线图证据，不能外推公开客户部署规模。https://www.marvell.com/company/newsroom/marvell-industry-first-2nm-optical-technology-ai-data-center-infrastructure-ecoc-2026.html
4. ⭐ **arXiv:2609.24570 把 400G SerDes 的 PAM4/PAM6/PAM8 与 MLSE 放到 GPU cluster 场景下做调制和均衡比较。** 论文摘要称其在 440 Gbps line rate、net 400G 条件下比较不同高阶调制在 bandwidth limitation 下的 BER/PSNR 权衡；它是理论和仿真研究，不是 silicon 实测或多厂商互操作结果。https://arxiv.org/abs/2609.24570

## 🔦 光学与光模块

1. 🔥 **Coherent 在 ECOC 2026 的组合展示把 3.2T pluggable、6.4T near-packaged optical engine、VCSEL scale-up optics 和 pluggable line system 覆盖到 scale-up、scale-out 与 scale-across。** 官方稿列出 3.2T OSFP-size pluggable、6.4T NPO engine、high-density 2D VCSEL/photodiode arrays 和 LS200 full C-band pluggable line system；下一步要看公开功耗、热设计、可维护性和独立互操作测试。https://www.coherent.com/news/press-releases/showcases-optical-innovations-scale-ai-infrastructure-ecoc-2026
2. 🔥 **Lightmatter Passage L20 CPX 把 BiDi 光链路推到 Open CPX MSA 语境，焦点是 scale-up pod 的 fiber/connector 数量而不只是总带宽。** 公司公告称 Passage L20 CPX 为 bidirectional CPX optical engine，设计 12.8 Tbps total bandwidth（6.4 Tbps transmit + 6.4 Tbps receive），32 optical lanes per direction，212.5 Gbps PAM4 line rate；评估套件预计 2027 Q1，实际 TCO 仍需客户侧数据验证。https://lightmatter.co/press-release/lightmatter-joins-open-cpx-msa-introduces-the-industrys-first-bidirectional-cpx-optical-engine/
3. ⭐ **Lumentum 的 ECOC 2026 日程显示 800G/1.6T silicon photonic transmitters、1060 nm VCSEL arrays 与 AI fabric panel 并行推进。** 这说明短距 AI 光互连短期不会只有一种形态：pluggable SiPh、VCSEL D2D optics、NPO/CPO 和 external laser source 都在围绕 reach、功耗、fiber count 与 serviceability 做取舍。https://www.lumentum.com/en/events/ecoc-2026
4. ⭐ **Nokia 将 1.6T LPO、448G per lane preview、hybrid SiPh+TFLN coherent front-end 放在 ECOC 展示中，强调 intra data center 与 coherent front-end 的共同升级。** 官方页面提到 ultra-low power 1.6T LPO module 和 next generation 448G per lane transmission preview；这些是路线图和展示信号，不等同于已经公开规模量产。https://www.nokia.com/events/nokia-at-ecoc/
5. ⭐ **光迅科技在 ECOC 2026 展示 12.8T XPO DR 液冷光模块，为国内高密度 AI 集群光互连提供可观察样本。** 公司新闻称该模块采用 LRO 架构并现场展示实时数据，同时将 12.8T XPO 与传统 1.6T OSFP 在交换容量和机架空间上做对比；暂无第三方独立评测或客户规模部署证据。https://www.accelink.com/lighting_your_dreams/2101916634963804161.html

## 🖥️ AI服务器与超节点

1. 🔥 **ECOC 2026 special symposium 把 AI/ML 互连拆成 scale-up fabric 和 scale-out network 两层，这比单看 InfiniBand/Ethernet 或 CPO/pluggable 更接近系统现实。** 官方议程称 scale-up fabrics 紧耦合 XPU、memory 与 switching，形成 coherent "virtual XPU"，scale-out networks 连接多个 scale-up fabric；议题覆盖 silicon photonics、glass substrate co-packaging、DWDM external laser、VCSEL fiber bundle connector、CPO manufacturing path 和系统厂商视角。https://ecoc2026.org/ecoc2026/programme/specialsymposia
2. 🔥 **VIAVI 的 1.6T AI fabric validation 将测试范围从光模块扩展到 L0-L3、workload emulation 和 Ultra Ethernet Transport。** 官方稿称 TestCenter D2 面向 1.6T Layers 2/3 与 AI workload testing，可识别 interconnect bottlenecks、latency hotspots 和 fault-tolerance gaps；这说明超节点上线的痛点包含 optics、switch silicon、protocol、telemetry 与故障注入。https://www.viavisolutions.com/ru-ru/node/134635
3. ⭐ **Lightmatter 的 BiDi 技术文章把 512-GPU scale-up model 中的 fiber count、connector count 与 network spend 量化为工程约束。** 公司估算 BiDi 可把 fiber 和 connector 数量减半，并降低约 15% scale-up network spend；这是公司模型，不是第三方评测，但它点出了大规模 GPU pod 在清洁、插拔、布线和故障定位上的现实成本。https://lightmatter.co/resource/one-fiber-two-directions-the-case-for-bidirectional-optics-in-ai-data-center-scale-up-networks/
4. 📌 **截至本次日报，公开来源仍未给出 ECOC 2026 展示方案在真实客户 AI 集群中的独立性能评测、批量良率或量产替换节奏。** 因此本日报把 1.6T/3.2T pluggable、6.4T NPO、12.8T XPO、Open CPX、448G electrical signaling 与 test platform 视为公开 demo、标准互操作或厂商路线图证据。https://www.ecocexhibition.com/

2. 🔥 **NTT IOWN AI Fund 投资 iPronics，显示 programmable optical networking 正进入 AI data center 资本主题。** NTT 官方稿称 iPronics 的 silicon photonics programmable optical connectivity 面向突破 copper interconnects 与 fixed network configurations 的限制，支持 scalable、power-efficient AI infrastructure；这仍是投资和技术方向信号，不代表公开大规模商用。https://www.group.ntt/en/newsrelease/2026/09/09/260909a.html
3. ⭐ **Tower Semiconductor 的 SiPh/SiGe foundry 展示提醒市场：CPO/NPO 的瓶颈不只在光引擎设计，也在 PDK、wafer-level test、packaging 与高可靠制造。** 官方稿称其 Silicon Photonics platform 覆盖 datacenter/telecom optical transceivers，并面向 NPO/CPO、DWDM lasers、optical circuit switching 等应用；对 AI optics 来说，产能和良率会决定路线图能否转化成系统供货。https://towersemi.com/2026/09/15/09152026/
4. ⭐ **国内 CIOE 2026 公开报道显示 1.6T、3.2T、6.4T NPO 与 12.8T XPO 进入密集展示期，但客户、订单和量产节奏仍需公司公告验证。** 每日经济新闻现场报道称新易盛、华工科技等厂商展示高速光模块和 AI 数据中心相关方案；对投资和产业判断，应把媒体报道与公司公告、客户侧采购、第三方测试分开处理。https://www.nbd.com.cn/articles/2026-09-11/4579130.html

## 📄 论文速递

1. 🔥 **arXiv:2609.24570 - "Advanced 400G-SerDes Modulations and Equalizers for GPU Cluster in AI Era"。** 论文比较 PAM4、PAM6、PAM8 与 MLSE 在 400G SerDes 场景下的 BER、bandwidth limitation 与 PSNR 权衡，适合作为 400G/lane electrical I/O 后续调制路线的技术参考。https://arxiv.org/abs/2609.24570
2. ⭐ **arXiv:2609.21830 - "Performance of Capacitively Loaded RF Electrodes on SiO2/Si Substrates for High-Speed Electro-Optic Modulators"。** 论文研究 thermally grown SiO2/high-resistivity silicon 上的 traveling-wave RF electrodes，摘要称 RF attenuation 可低至约 0.23 dB/cm/sqrt(GHz)，对 TFLN/TFLT modulators 与 co-packaged optical systems 的 RF interconnect 有参考价值。https://arxiv.org/abs/2609.21830
3. ⭐ **arXiv:2609.20686 - "Volumetric Evanescent Edge Coupling for Fiber-to-Chip Optical I/O"。** 论文提出 volumetric edge coupling，把 chip edge 的耦合从单行扩展到二维区域；摘要报告 1550 nm 仿真峰值耦合效率 88%（-0.56 dB）和 86.45 nm 1-dB bandwidth，适合跟踪 CPO/optical I/O 的封装与光引出问题。https://arxiv.org/abs/2609.20686
4. 📌 **arXiv:2609.24108 - "Hypervectors from Optical Disorder: Programmable Encoding and Optical Inference for Hyperdimensional Computing"。** 论文偏 optical computing/photonic inference，利用 silicon photonic circuit 与 scattering medium 生成 high-dimensional hypervectors；它不是数据中心互连论文，但对低功耗 photonic inference 和片上光学随机性有启发。https://arxiv.org/abs/2609.24108
