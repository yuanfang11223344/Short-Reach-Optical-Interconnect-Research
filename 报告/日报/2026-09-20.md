## 🔌 SerDes与互连技术

1. 🔥 **ECOC 2026 Conference 今天开幕，短距互连的观察窗口从“会前预告”进入“现场论文、展台和互操作证据”阶段。** 官方页面显示会议为 2026-09-20 至 2026-09-24，展会为 2026-09-21 至 2026-09-23；本周应重点区分论文/展台 demo、multi-vendor interop、产品 sampling 和真实客户部署，避免把现场演示直接写成规模量产。https://ecoc2026.org/ECOC2026
2. 🔥 **OIF @ ECOC 2026 的 39 家会员互操作仍是 224G/448G electrical I/O 与 CPO/NPO 管理接口的核心验证清单。** OIF 官方页面把 live demo 范围写成 Optical Systems、448G and 224G Common Electrical I/O、CMIS、Co-Packaging、Energy Efficient Interfaces 等方向；对 SerDes 团队，最有价值的信息不是单一 lane rate，而是 host、module、test equipment、FEC、BER、link training 与管理接口边界。https://www.oiforum.com/meetings-events/oif-ecoc-2026/
3. ⭐ **Astera Labs 的 400G-per-lane 文章把 copper 与 optical 的边界重新拉回系统工程问题。** 官方博客强调 AI infrastructure 正走向 400G per lane，并讨论 retimer、active electrical cable、linear pluggable optics 与 co-packaged optics 在距离、功耗、复杂度和可维护性上的取舍；这有助于把“光进板/进封装”放在可操作的分层架构里评估。https://www.asteralabs.com/resources/blog/the-400g-per-lane-inflection-point-where-copper-and-optical-meet-in-ai-infrastructure/
4. ⭐ **UALink 与 UEC 继续形成 scale-up / scale-out 双栈参照系。** UALink 官网强调 accelerator-to-accelerator open standard 与 multi-workload deployment，UEC 官网强调面向 AI/HPC at scale 的 open Ethernet stack；短距互连选型需要同时跟踪 rack 内低延迟一致性语义和 rack 间 Ethernet 拥塞控制、tail latency、telemetry。https://ualinkconsortium.org/  https://ultraethernet.org/

## 🔦 光学与光模块

1. 🔥 **OIF 会前材料把 CPO/NPO、CMIS 与 EEI 放进同一个现场互操作叙事，说明光模块竞争点正在从 form factor 扩展到管理、能效和可测性。** 这类 demo 若能披露 CMIS 状态机、host-module interop、power state、thermal telemetry 和测试仪表组合，将比单独展示 1.6T/3.2T 光模块更有系统价值。https://www.oiforum.com/oif-validates-ai-era-interoperability-live-at-ecoc-2026-through-multi-vendor-demonstrations-and-expert-sessions/
2. 🔥 **Open CPX MSA 的 7.2T socket / 200G per lane 规范仍是本周 CPO/NPO 生态化的关键背景。** 公开新闻称该规范面向 high-density pluggable CPO/NPO modules，覆盖 6.4T/7.2T modules 和 mixed-media CPX form factor；今天的判断仍然保守：它是多厂商 socket 规则，不等同于公开客户集群量产。https://sg.finance.yahoo.com/news/open-cpx-msa-group-releases-100000093.html
3. ⭐ **Avicena 的 connectorized microLED optical interconnect 把问题从器件效率推进到封装装配和现场维护。** 公司新闻稿强调 detachable/reconnectable inline optical link、multicore fiber、LightBundle eKit 与 link performance/BER monitoring；这条路线值得盯 ECOC 展示的 BER、connector repeatability、thermal envelope 和可维护性证据，暂无独立评测。https://avicena.tech/press-releases/
4. ⭐ **OpenLight 继续以 3.2T DR8 PIC、1.6T/3.2T PASIC 和 InP-on-silicon 平台切入 terabit optics。** 官网显示其 ECOC 2026 展位与 400G per lane modulators、3.2T DR8 PIC 等方向；适合记录 silicon photonics manufacturing readiness 与 PIC-level integration 线索，不宜外推成某云厂商已部署。https://openlightphotonics.com/

## 🖥️ AI服务器与超节点

1. 🔥 **AI Infra Summit 2026 收官后，Data Movement 仍是超节点讨论的主线。** 官方页面把 Astera Labs、Ayar Labs、Lightmatter、Marvell、Micron、Nokia、Samsung、Samtec、SK hynix 等归入 Data Movement 相关生态，说明 AI server 竞争点正在跨越 GPU、HBM、PCIe/CXL、Ethernet、optical I/O 与运维软件栈。https://www.ai-infra-summit.com/data-movement
2. 🔥 **Marvell 的 AI data center connectivity portfolio 把 Photonic Fabric、RELIANT telemetry、Teralynx T100、PCIe 6.0 和 CXL memory solutions 放在同一叙事里。** 对超节点而言，这意味着 scale-up、scale-out、scale-across 正被同一供应链组合打包评估，互连芯片的价值正在与 telemetry、resource pooling、failure isolation 一起被定价。https://investor.marvell.com/news-events/press-releases/detail/1032/marvell-to-showcase-end-to-end-ai-data-center-connectivity-portfolio-at-ai-infra-summit-2026
3. ⭐ **SK hynix 的 AI Memory 叙事继续把 HBF、PIM、eSSD、SALT-KV 与 AI infrastructure 串联。** 官网 9 月中旬动态显示其围绕 AI Infra Summit 讨论 AI memory spectrum；互连角度的启发是，KV cache、checkpoint、prefill/decode 分离和存储层级会继续影响 GPU fabric 需求，而不是被单一光互连路线完全解决。https://news.skhynix.com/en/
4. ⭐ **arXiv:2609.10790 把 composable CXL memory 做成 Kubernetes-native shared memory，用于 LLM serving 的 KV-cache reuse。** 论文报告两节点、512 GiB CXL appliance、Qwen2.5-7B-Instruct 场景下的可行性，并把 CXL region 暴露为 Kubernetes DRA/CDI 可调度资源；这不是全面产品评测，但很好地展示了内存互连和云原生调度的交汇点。https://arxiv.org/abs/2609.10790

1. 🔥 **ECOC 与 AI Infra Summit 的时间相接，使本周成为“数据中心光互连从 slide 进入现场证据”的密集窗口。** AI Infra Summit 讨论 data movement、AI data center、operations，ECOC 则给出 optical communication、coherent、silicon photonics 与 data center optics 现场；基础设施评估应把 power/cooling、fiber plant、telemetry、repairability 和 procurement ecosystem 一起纳入。https://www.ai-infra-summit.com/  https://www.ecocexhibition.com/
2. 🔥 **Corning / Verizon 的多年高密度光纤协议提醒 scale-across AI 的物理层不止在机柜内。** 官方新闻稿称 2027-2032 年协议覆盖 80+ million miles 高密度光纤与连接解决方案，用于 broadband expansion 和 next-gen AI infrastructure；这类供给链信号会影响 campus、metro 与 long-haul data center interconnect，而不是直接证明某个 rack 内互连方案胜出。https://www.corning.com/worldwide/en/about-us/news-events/news-releases/2026/09/verizon-and-corning-announce-multi-year-multi-billion-dollar-supply-agreement-for-broadband-expansion-and-next-gen-ai-infrastructure.html
3. ⭐ **arXiv:2609.11649 的 grid-to-chip 框架继续给互连路线设边界条件。** 论文把 medium-voltage interface、higher-voltage DC distribution、solid-state transformers、wide-bandgap devices、chip-level power delivery、liquid cooling 与 rack/facility/grid 稳定性放到同一个 AI data center 模型中；CPO、OCS、high-radix fabric 的收益最终要经受供电和冷却约束检验。https://arxiv.org/abs/2609.11649
4. 📌 **暂无独立评测能证明某个 CPO/NPO、Photonic Fabric 或 microLED optical I/O 方案已经在公开客户 AI 集群中大规模替代 OSFP、铜缆或既有 Ethernet fabric。** 本日报只记录公开规范、展会 demo、论文与官方路线；涉及功耗、客户、量产时间和集群性能，仍按一手来源边界处理。https://www.oiforum.com/meetings-events/oif-ecoc-2026/

## 📄 论文速递

1. 🔥 **arXiv:2609.20686 - "Volumetric Evanescent Edge Coupling for Fiber-to-Chip Optical I/O"。** 论文提出 volumetric edge coupling，把 fiber-to-chip optical I/O 从单行 chip facet 通道扩展到二维区域；摘要称仿真给出 1550 nm 峰值耦合效率 88%（-0.56 dB）和 86.45 nm 1-dB bandwidth，适合作为 multicore fiber / CPO 光 I/O 密度研究线索，仍需制造和封装验证。https://arxiv.org/abs/2609.20686
2. 🔥 **arXiv:2609.01821 - "Scaling Inference Prefill with High-Radix Photonic Interconnects"。** 论文建模比较 copper-based GPU systems 与 high bandwidth integrated photonics，在通信受限推理 prefill 场景讨论 high-radix photonic interconnect 的潜在收益；它是 workload-level 建模证据，不是实机部署评测。https://arxiv.org/abs/2609.01821
3. ⭐ **arXiv:2609.09400 - "QPS-ToR: A Parallel Iterative Switching Algorithm for Reconfigurable Optical Datacenter Switching"。** 论文聚焦 reconfigurable optical datacenter network 的 ToR scheduling，说明 optical circuit switching 的瓶颈同样在调度算法和控制面，而不只在光器件。https://arxiv.org/abs/2609.09400
4. ⭐ **arXiv:2609.15889 - "Cnuas: A Software-Defined AI/HPC Rack-scale Emulation Platform and Hyperscale Data Center Facility Twin"。** 论文基线覆盖 RDMA adapter、RoCEv2/native InfiniBand hybrid switch、accelerator peer fabric、OpenBMC rack management 与 power/battery firmware；价值在 rack-scale 软件/固件/管理验证，而不是宣称匹配真实硬件吞吐。https://arxiv.org/abs/2609.15889
5. 📌 **arXiv:2609.04025 - "THz-SynC: Collective Synthesis with Contextual-Bandit-Assisted Coordination for Reconfigurable Hybrid Optical-THz AI Datacenters"。** 论文把 THz rack-to-rack wireless link 作为 optical fabric 的补充来优化 collective workloads；这是研究型 hybrid fabric，不应外推为近期量产 data center interconnect。https://arxiv.org/abs/2609.04025
