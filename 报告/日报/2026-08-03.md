## SerDes与互连技术

1. 🔥 **OIF 将在 ECOC 2026 展示 448G/224G CEI、optical systems 与 Common Management 互操作。** 这条新闻的价值在于，448G 不再只是 framework 讨论，行业开始把 448G VSR/LR、224G CEI 和模块管理放到同一互操作场景中验证，直接影响下一代 switch ASIC、optical module、retimer 和测试仪表的开发优先级。来源：https://www.oiforum.com/oif-brings-industry-wide-interoperability-to-life-at-ecoc-2026-accelerating-scalable-efficient-networks-for-the-ai-era/
2. 🔥 **IEEE P802.3dj 继续作为 200G/lane、800GbE 和 1.6TbE 的标准节拍器。** 近期公开 session 资料仍显示 PHY/PMD、electrical interface、optical interface 与 comment resolution 是核心工作；对供应链而言，224G/200G-lane SerDes、connector、PCB material 和 compliance test 都要围绕该节奏排产。来源：https://www.ieee802.org/3/dj/
3. ⭐ **OIF CEI-224G-Linear 项目明确面向 LPO、CPO、NPO 和 full linear optical modules。** 该项目把低功耗、低成本和低延迟放在同一目标下，说明 AI/ML network 的短距链路会继续在 retimed、half-retimed 和 linear 方案之间做系统级取舍。来源：https://www.oiforum.com/technical-work/current-work/
4. ⭐ **Ethernet Alliance 在 OFC 2026 的 AI-scale Ethernet 演示继续强化 multi-vendor interoperability。** 产业信号是 1.6T Ethernet 生态不仅需要单点 ASIC 或模块可用，还需要 switch、NIC、optics、cable、test equipment 之间形成可展示的端到端链路。来源：https://ethernetalliance.org/blog/2026/03/03/ai-scale-ethernet-at-the-heart-of-ethernet-alliances-ofc-2026-demo/
5. **Ultra Ethernet Consortium 的公开规范继续把 transport、congestion control、telemetry 和 software stack 放进 AI/HPC Ethernet。** 对 scale-out 网络而言，链路速率之外的尾延迟、拥塞恢复和作业可观测性正在成为训练效率约束。来源：https://ultraethernet.org/
6. **UALink 继续提供开放 accelerator-to-accelerator scale-up 互连路线。** 它与 NVLink、Infinity Fabric 等厂商方案并行，关键看 endpoint、switch ASIC、collective library 和系统软件能否形成可验证生态。来源：https://www.ualinkconsortium.org/

1. 🔥 **OIF EEI 与 COI 文档把“节能 photonic interconnect”提升为 AI compute scale-up 问题。** OIF informative documents 中的 Energy Efficient Interfaces 与 Compute Optics Interface 白皮书说明，未来光互连评估重点会从单模块速率扩展到 pJ/bit、可维护性、link training 和系统边界。来源：https://www.oiforum.com/documents/informative-documents/
2. 🔥 **TechRadar 本周讨论 silicon photonics 对 AI data center 的作用，重点落在 CMOS compatibility、能耗和热问题。** 这类产业解读的信号是，silicon photonics 已从长距通信外溢到 AI cluster 内部数据移动，制造一致性和供应链协同将影响采用速度。来源：https://www.techradar.com/pro/how-silicon-photonics-lights-the-way-for-data-centers
3. ⭐ **OCP China Day 2026 将 AI data center interconnect、OCP 协作和基础设施论坛放在同一议程中。** 对国内供应链而言，open rack、optical interconnect、power/cooling 和 module ecosystem 的耦合度正在提升。来源：https://www.opencompute.org/events/past-events/2026-ocp-china-day
4. **Ethernet Alliance 技术负责人复盘 OFC 2026，强调 high-speed Ethernet、AI scale-out 和多厂商网络环境。** 这进一步确认 800G/1.6T optics 的商业节奏依赖互操作验证，而不是只看单个光模块 vendor 的样品指标。来源：https://ethernetalliance.org/blog/2026/05/27/ofc-2026-the-tech-leads-perspective/
5. **Marvell 将 AI infrastructure scale-up/scale-out/scale-across 与 1.6T connectivity、224G Long-Reach SerDes 放在同一解决方案叙事中。** 其公开资料显示 optical DSP、SerDes、switching 和 custom silicon 的边界正在被 hyperscale AI 架构重新划分。来源：https://www.marvell.com/solutions/data-center/scaling-ai-infrastructure.html
6. **Broadcom 的 optical DSP 产品线继续作为 800G/1.6T pluggable 与 switch silicon 协同的参考。** 对模块厂和系统厂而言，DSP 功耗、FEC、host interface 与 thermal envelope 会共同决定部署成本。来源：https://www.broadcom.com/products/ethernet-connectivity/optical-dsp

## AI服务器与超节点

1. 🔥 **NVIDIA Spectrum-X 仍是 AI Ethernet scale-out 的公开样板。** NVIDIA 将 Spectrum-X 定位为面向 AI cloud 的 accelerated Ethernet platform，产业讨论围绕 RoCE、adaptive routing、congestion control、telemetry 与端到端软件调优展开。来源：https://www.nvidia.com/en-us/networking/ethernet/spectrum-x/
2. 🔥 **NVIDIA networking moat 讨论升温，开放 Ethernet 接口与 proprietary implementation 并存。** SiliconANGLE 的评论指出，Spectrum-X 支持标准 Ethernet/RoCE 与多网络操作系统，但系统级 co-design 仍带来生态绑定争议；这正是开放 UEC/UALink 阵营需要回答的问题。来源：https://siliconangle.com/2026/07/16/nvidias-ai-networking-moat-real-lock-debate-continues/
3. ⭐ **NVLink 继续作为 rack-scale scale-up fabric 的性能基准。** 对 UALink、Scale-Up Ethernet 和 optical scale-up 方案来说，比较对象不是单条链路速率，而是 collective performance、memory semantics、fault domain 和软件生态。来源：https://www.nvidia.com/en-us/data-center/nvlink/
4. **Marvell 的 scale-up/scale-out/scale-across 框架说明 AI 集群网络正在分层。** Rack 内、rack 间、园区间互连分别面临不同的 reach、latency、power 和 serviceability 约束，单一介质很难覆盖全部层级。来源：https://www.marvell.com/solutions/data-center/scaling-ai-infrastructure.html
5. **OCP Pod and Cluster Network Interconnects for AI 议题继续适合作为开放网络架构素材。** 它把 AI pod、cluster network 和开放基础设施连接起来，有助于比较 proprietary fabric 与 open Ethernet/optical approaches。来源：https://www.opencompute.org/events/past-events/dc-it-infrastructure-workshop-pod-and-cluster-network-interconnects-for-ai

## 论文速递

1. 🔥 **3D optoelectronics and co-packaged optics: when solving the wrong problems stalls deployment。** 论文认为 CPO 不是器件级优化，而是改变 photonics/electronics/system design 边界的架构承诺；标准化、可维护性和 thermal-aware co-design 会决定 AI-scale datacenter 部署成败。来源：https://arxiv.org/abs/2603.21313
2. 🔥 **Scheduling Parallel Optical Circuit Switches for AI Training。** 论文从 AI training 的重复 collective communication pattern 出发，讨论 parallel OCS scheduling，适合跟踪 OCS 是否能缓解传统 packet network 的带宽与功耗压力。来源：https://arxiv.org/abs/2603.07373
3. ⭐ **LLMs and Optical Networks: A Symbiotic Relationship。** 论文讨论 LLM 与 optical network lifecycle management/control automation 的互相作用，对未来 AI data center 网络运维自动化有参考价值。来源：https://arxiv.org/html/2606.30278v1
4. ⭐ **Harnessing Photonics for Machine Intelligence。** 论文从 AI acceleration 的 power、memory 和 interconnect limit 出发，讨论 integrated photonics 如何用于数据移动和计算；可作为 photonic compute 与 optical I/O 边界讨论素材。来源：https://arxiv.org/html/2604.10841v1
5. **InfiniteHBD: Building Datacenter-Scale High-Bandwidth Domain for LLM with Optical Circuit Switching Transceivers。** 论文提出在 transceiver 级别嵌入 OCS，以形成可重构 high-bandwidth domain；需要重点评估成本、控制平面和故障隔离假设。来源：https://arxiv.org/html/2502.03885v5
