## 🔌 SerDes与互连技术

1. 🔥 **OIF current work 继续把 CEI-224G 与 CEI-448G 放在 AI short-reach 电接口主线。** CEI-224G-XSR 面向 D2D/D2OE，目标至少 50 mm package substrate；CEI-224G-VSR/MR/LR 分别覆盖 chip-to-module、chip-to-chip 和 backplane/copper cable；CEI-448G-VSR/LR 则把 448G PAM4 推向 c2m 与 backplane。对 2027 前后的 AI switch/accelerator I/O，测试、封装材料和连接器预算会比单颗 SerDes 指标更关键。https://www.oiforum.com/technical-work/current-work/
2. 🔥 **Marvell scale-up networking 方案把 224G production-proven SerDes、448G technology、CPC、electrical/optical I/O chiplets 与 UALink/ESUN/NVLink-compatible switching 放进同一个数据中心互连栈。** 这类叙事说明 scale-up 已不再等同于单一 proprietary link，而是 copper package escape、optical reach、switch ASIC、memory/accelerator attach 和软件生态的组合竞争。https://www.marvell.com/blogs/scale-up-network-solutions-for-ai-infrastructure.html
3. ⭐ **Cisco Secure AI Factory with NVIDIA 将前端 fabric 的 Cisco Silicon One 与后端 fabric 的 NVIDIA Spectrum-X Ethernet switch silicon 统一到 Nexus One 架构。** 官方 FAQ 称这是 NCP-compliant rack-scale reference architecture 的组成部分，并允许 NX-OS 或 SONiC；对 AI Ethernet 采购来说，互连验证会从端口速率扩展到前后端网络、storage network、security 和 observability 的全栈一致性。https://www.cisco.com/c/en/us/solutions/collateral/artificial-intelligence/cisco-secure-ai-factory-nvidia-rackscale-faq.html
4. ⭐ **UEC Specification 1.0 已把 NIC、switch、optics 和 cables 纳入面向 AI/HPC 的 Ethernet stack。** UEC 官方材料强调高性能、可扩展、多供应商互操作，并减少对 Ethernet 生态的非必要改动；后续关注点是 UET transport、拥塞控制、collective 通信和大规模互操作测试是否进入可部署阶段。https://ultraethernet.org/ultra-ethernet-consortium-uec-launches-specification-1-0-transforming-ethernet-for-ai-and-hpc-at-scale/

## 🔦 光学与光模块

1. 🔥 **Eoptolink 在 OFC 2026 展示 12.8 Tbps liquid-cooled pluggable XPO，目标覆盖 AI data center 的 scale-up、scale-out 与 metro-reach fabrics。** 这类产品把 pluggable optics 推到液冷、超高密度和更靠近系统级热设计的边界；需要继续验证的是功耗、可维护性、连接器生态和交换机侧 host electrical interface。https://eoptolink.com/news/13-new-products/364-eoptolink-joins-xpo-msa-and-unveils-industry-first-12-8-tbps-liquid-cooled-pluggable-optics-for-ai-data-centers
2. 🔥 **Eoptolink 6.4T NPO 采用 32 lanes x 200 Gbps，并基于 Silicon Photonics 面向 near-packaged optical transceiver。** 这与 OIF 12.8T/6.4T NPO 项目的方向一致：NPO 不是简单缩短线缆，而是把光模块放进 ASIC 周边的供电、散热、光源和连接器协同设计。https://www.eoptolink.com/news/13-new-products/366-eoptolink-unveils-high-density-6-4t-npo-solution-at-ofc-2026
3. ⭐ **Eoptolink 1.6T DR4 演示把 8x200G electrical interface 映射到 4x400G optical interface，较 1.6T DR8 降低 50% fiber count。** 这是从 200G/lambda 量产爬坡向 400G/lambda 验证过渡的典型路线，但短期仍要看 DSP、EML/SiPh、测试仪表和模块热设计是否同步成熟。https://eoptolink.com/news/13-new-products/365-eoptolink-demos-imdd-400g-per-lambda-based-1-6t-dr4-optical-transceiver-solution-at-ofc-2026
4. ⭐ **Source Photonics 与 Delta 在 OFC 2026 演示 1.6T transceiver 与 switch products，并披露 100GBd EML 支持 200Gb/s single-lambda PAM4。** 其 1.6T 系列覆盖 DR8、2xFR4、2xLR4，800G 系列覆盖 DR4/FR4/LR4；这说明 200G/lambda 供应链正在从样品演示转向更完整的产品族和交换机联调。https://www.sourcephotonics.com/news/source-photonics-and-delta-electronics-join-force-to-demo-1-6t-transceiver-and-switch-products-at-ofc26/
5. 📌 **Coherent 首页显示 1.6T-DR8 transceiver 采用 silicon photonics 和 Marvell Ara 3nm optical DSP，并使用 200 Gbps electrical/optical interfaces。** 同页还披露 300mm high thermal conductivity SiC substrates 已开始向 AI semiconductor partners sampling；这把光模块、材料散热和 AI 半导体封装放到同一供应链视角。https://www.coherent.com/

## 🖥️ AI服务器与超节点

1. 🔥 **Cisco 扩展 Secure AI Factory with NVIDIA，纳入 Supermicro liquid-cooled 与 air-cooled compute systems，计划 2026 年 10 月开始提供。** 官方公告强调 rack-scale capability、NCP validation、Cisco Validated Infrastructure Services，以及 compute/NIC/optics/network metrics 的端到端 observability；这说明企业/neo cloud 的 AI supernode 采购正在转向可验证的整柜方案。https://newsroom.cisco.com/c/r/newsroom/en/us/a/y2026/m08/cisco-secure-ai-factory-nvidia-rack-scale.html
2. 🔥 **Cisco FAQ 明确 Supermicro NVIDIA NVL72 rack-scale AI systems、NVIDIA HGX/MGX dense GPU servers 可纳入 Cisco 授权渠道组合。** 同一 FAQ 提到现代 NVL72 级系统可超过 200 kW/rack，liquid cooling 从可选项变为系统级要求；互连工程必须把 switch、NIC、optics、CDU 和服务器热设计一起验证。https://www.cisco.com/c/en/us/solutions/collateral/artificial-intelligence/cisco-secure-ai-factory-nvidia-rackscale-faq.html
3. ⭐ **NVIDIA Vera Rubin NVL72 官方资料继续强化 sixth-generation NVLink 的 rack-scale bandwidth 叙事。** NVIDIA 新闻稿称每颗 Rubin GPU 提供 3.6 TB/s NVLink bandwidth，Vera Rubin NVL72 rack 提供 260 TB/s rack bandwidth，并由 NVLink 6 switch 支持 collective/in-network compute；这会继续拉高 scale-up electrical/optical I/O、connector 和液冷系统压力。https://nvidianews.nvidia.com/news/rubin-platform-ai-supercomputer
4. ⭐ **AMD open rack-scale AI infrastructure 方案中，Pensando “Vulcano” AI NIC 被描述为 UEC 1.0 compliant，并支持 PCIe 与 UALink 接口、800G network throughput。** 这提示开放 scale-out Ethernet 和 accelerator scale-up link 会在 NIC/SmartNIC 层交汇；后续需要观察实际硅片、软件栈和互操作认证。https://www.amd.com/en/blogs/2025/amd-delivering-open-rack-scale-ai-infrastructure-to-unlock-agentic-ai.html

## 📄 论文速递

1. 🔥 **arXiv:2608.11639 — “Towards Terabit/λ/s Multidimensional Silicon Photonic Engine”。** 论文面向 AI factories 的 optical interconnect，提出 multidimensional silicon photonic engine，并给出单波长/每秒 Tb 级通信能力方向；适合作为降低 fiber/connector 压力的研究路线，但工程化仍取决于封装、温控、可靠性和量产测试。https://arxiv.org/abs/2608.11639
2. 🔥 **arXiv:2608.03146 — “Zero-change foundry compatible silicon photonics MEMS optical switch”。** 论文称 large-scale photonic switches 是 data center 与 AI/ML clusters 的 energy-efficient optical interconnect 关键器件，并展示 foundry-compatible MEMS + silicon photonics 路线；后续看点是阵列规模、插损一致性和封装寿命。https://arxiv.org/abs/2608.03146
3. ⭐ **arXiv:2605.21187 — “High-speed Networking for Giga-Scale AI Factories”。** 论文描述 Spectrum-X multiplane architecture、NIC/switch hardware-accelerated load balancing 和大规模 AI training 网络评估，摘要给出 98% theoretical line rate、低 jitter latency、cross-tenant isolation 与 link failure 下的容量比例退化；可作为 AI Ethernet fabric 设计的参考，但需区分论文评估环境与第三方独立复现。https://arxiv.org/abs/2605.21187
4. ⭐ **arXiv:2606.25098 — “Power-Flexible AI Data Centers”。** 论文讨论 AI data center 作为 grid-responsive compute 的架构，并在 130 kW GPU cluster 上展示负载削减、持续 curtailment 和 carbon-aware operation；这对高密度互连的意义是，网络与作业调度需要适应电力约束，而不是默认满功率连续运行。https://arxiv.org/abs/2606.25098
5. 📌 **arXiv:2605.28971 — Micro-transfer printing of lithium niobate on 200 mm silicon photonics。** 摘要把 TFLN-on-SiPho 的 wafer-scale heterogeneous integration 与 AI/data-center photonic interconnect 需求相连；材料和工艺平台若能规模化，会影响高速 modulator、光 I/O 和 CPO 供应链。https://arxiv.org/abs/2605.28971
