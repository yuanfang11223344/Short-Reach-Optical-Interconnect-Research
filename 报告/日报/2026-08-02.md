## SerDes与互连技术

1. 🔥 **IEEE P802.3dj 仍是 200G/lane 与 1.6TbE 生态的关键节拍器。** IEEE 802.3dj task force 面向 200 Gb/s electrical/lane、800GbE 和 1.6TbE PHY/PMD 继续推进，今天的产业含义是：交换芯片、线缆、retimer、光 DSP 和测试仪表都在围绕 200G/lane 做前置设计。来源：https://www.ieee802.org/3/dj/
2. ⭐ **OIF 的 CEI-224G 工作继续定义芯片到模块、芯片到芯片短距电接口边界。** 对 AI 服务器而言，224G electrical I/O 不只是速率升级，更决定 CPO/NPO、LPO/半有源铜缆和 pluggable 光模块之间的功耗拆分。来源：https://www.oiforum.com/technical-work/hot-topics/cei-224g/
3. **Ultra Ethernet Consortium 把 AI/HPC workload 放在以太网演进中心。** UEC 的公开目标是针对 AI 与 HPC 改进 Ethernet 的传输、拥塞控制、遥测和软件栈，直接对应 scale-out cluster 对低尾延迟和可观测性的要求。来源：https://ultraethernet.org/
4. **UALink 继续补齐 accelerator-to-accelerator scale-up 互连标准空白。** UALink Consortium 公开将 specification 面向开放 AI accelerator 互连生态，和 NVLink/Infinity Fabric 等厂商方案形成并行路线。来源：https://www.ualinkconsortium.org/
5. **PCI-SIG 的 PCIe 7.0 目标把 board-level channel 设计压力继续前移。** PCIe 7.0 公开目标为 128 GT/s，面向 2025 后规范成熟；对 2026 服务器主板、retimer 和连接器预研仍有直接牵引。来源：https://pcisig.com/pci-express-7-0-specification

## 光学与光模块

1. 🔥 **OIF 继续把 1.6T coherent / 800ZR / 1600ZR 作为 DCI 和 AI 数据中心互连的公开焦点。** 对云厂商而言，数据中心园区间东西向流量增加，使 800G/1.6T coherent 与 pluggable DCI 的边界更受关注。来源：https://www.oiforum.com/technical-work/hot-topics/
2. ⭐ **Open Compute Project 的 Co-Packaged Optics 方向仍是 hyperscale 交换机功耗约束下的长期选项。** OCP 对 CPO、open networking 和 data center facility 的并行推进，说明光 I/O 不是单一模块问题，而是系统、供电、散热和可维护性协同问题。来源：https://www.opencompute.org/projects/co-packaged-optics
3. **Ethernet Alliance 继续用路线图方式锚定 800GbE/1.6TbE 产业协同。** 其公开 Ethernet roadmap 将 higher-speed Ethernet、AI/ML cluster、test/interop 串联，是判断交换 ASIC、optics 和测试生态节奏的重要参考。来源：https://ethernetalliance.org/technology/ethernet-roadmap/
4. **NVIDIA 公开展示 silicon photonics / co-packaged optics 方向，强调降低 AI factory 网络能耗。** 这支持一个行业判断：CPO 的核心卖点仍是 pJ/bit 和 radix，不是简单替代所有 pluggable optics。来源：https://www.nvidia.com/en-us/networking/ethernet/spectrum-x/
5. **Broadcom 持续把 100G/lane、200G/lane optical DSP 与 switch silicon 组合为 AI 网络基础部件。** 对系统厂商的启示是：switch ASIC radix、DSP 功耗、module thermal envelope 必须共同评估。来源：https://www.broadcom.com/products/ethernet-connectivity/optical-dsp

## AI服务器与超节点

1. 🔥 **NVIDIA Spectrum-X 继续作为 AI Ethernet scale-out 的公开样板。** NVIDIA 将 Spectrum-X 定位为面向 AI cloud 的 Ethernet networking platform，重点放在 adaptive routing、congestion control、RoCE 和端到端调优。来源：https://www.nvidia.com/en-us/networking/ethernet/spectrum-x/
2. ⭐ **NVIDIA NVLink / NVLink Switch 仍是 rack-scale scale-up 的对照基准。** 其公开资料强调 GPU 到 GPU 高带宽互连与交换结构，对开放 UALink 和以太网增强方案形成性能参照。来源：https://www.nvidia.com/en-us/data-center/nvlink/
3. **AMD Instinct 平台继续推动开放网络与开放 accelerator 互连讨论。** AMD 公开 MI300/MI350 路线和 ROCm 生态，强化非单一厂商 AI 集群对开放互连协议、以太网和软件栈的需求。来源：https://www.amd.com/en/products/accelerators/instinct.html
4. **Meta、Microsoft、Google 等 hyperscaler 的 AI 基础设施投资继续放大网络部件需求。** 公开资本开支和 AI infrastructure 表述说明，AI server demand 正在沿着交换 ASIC、光模块、AEC/DAC、供电与散热链条外溢。来源：https://investor.fb.com/financials/ ; https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast ; https://abc.xyz/investor/
5. **Scale-up 与 scale-out 的边界正在变成系统架构问题。** 单机柜内 accelerator fabric、跨机柜 Ethernet/InfiniBand、存储网络和 management network 必须共同设计，孤立比较单条链路速率意义有限。来源：https://www.opencompute.org/projects/server

## 计算中心与基础设施

1. 🔥 **AI 数据中心供电约束继续倒逼网络功耗优化。** Schneider Electric 的 data center 资料强调电力、冷却和能效管理；对互连行业的直接影响是每 bit 能耗和热设计余量会进入采购决策。来源：https://www.se.com/us/en/work/solutions/for-business/data-centers-and-networks/
2. ⭐ **液冷从“高端选项”转为 AI rack 的常规工程议题。** Vertiv 公开液冷方案覆盖 direct-to-chip 和 rear-door 等形态，说明交换机、光模块和电源模块的热布局需要同步重构。来源：https://www.vertiv.com/en-us/solutions/liquid-cooling/
3. **OCP 的 DC-MHS 与 facility 项目继续影响 AI 服务器可维护性。** 标准化机箱、电源、热插拔和管理接口会影响高密度互连线缆的布线、服务半径与故障替换。来源：https://www.opencompute.org/projects/dc-mhs
4. **CoreSite、Equinix 等 colocation 运营商强调 AI-ready capacity。** 对产业链而言，园区供电、冷却水、fiber path 和跨楼互连成为 AI cluster 选址的重要约束。来源：https://www.coresite.com/solutions/artificial-intelligence ; https://www.equinix.com/solutions/artificial-intelligence
5. **计算中心建设周期拉长，使网络部件的交付确定性更重要。** 光模块、AEC、switch 系统和电力设备交期不再只是采购问题，而会影响 GPU cluster 上线窗口。来源：https://www.gartner.com/en/information-technology/topics/data-center-infrastructure

## 论文速递

1. 🔥 **3D optoelectronics and co-packaged optics: when solving the wrong problems stalls deployment。** 论文把 CPO 从器件优化上升为系统架构承诺，强调标准化、可维护性和 thermal-aware co-design 对 AI-scale datacenter 部署成败的影响。来源：https://arxiv.org/abs/2603.21313
2. ⭐ **2.5D co-packaged optical I/O chipsets on a SiON/Si interposer for 4 x 100G optical interconnection。** 论文展示 SiON/Si interposer 上的 400Gb/s single-fiber optical transceiver，重点在 WDM、低损耗布线、InP active devices 与热/信号完整性。来源：https://arxiv.org/abs/2602.08284
3. **InfiniteHBD: Building Datacenter-Scale High-Bandwidth Domain for LLM with Optical Circuit Switching Transceivers。** 论文提出把 OCS 嵌入 transceiver，面向 LLM 训练构建可重构 high-bandwidth domain，值得跟踪其 fault isolation 与成本模型假设。来源：https://arxiv.org/abs/2502.03885
4. **Graded Index Couplers for Next Generation Chip-to-Chip and Fiber-to-Chip Photonic Packaging。** 论文面向 co-packaged optics 的 chip-to-chip / fiber-to-chip coupling，关注 passive assembly、alignment tolerance 与宽带耦合。来源：https://arxiv.org/abs/2503.00121
5. **Next generation Co-Packaged Optics Technology to Train & Run Generative AI Models in Data Centers and Other Computing Applications。** 论文报告 50 micron pitch polymer waveguide interface 原型，用于提升 optical beachfront density，是封装互连路线的可参考案例。来源：https://arxiv.org/abs/2412.06570
