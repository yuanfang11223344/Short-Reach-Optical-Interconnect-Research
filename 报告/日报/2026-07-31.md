## 🔌 SerDes与互连技术

1. 🔥 **Spectrum-6 把 scale-out Ethernet 推到 102.4T switch system 周期。** NVIDIA 7 月 21 日发布的 Spectrum-6 明确面向 Vera Rubin AI factories，支持 pluggable 与 co-packaged optics，两者会共同服务 100k+ GPU 级别的 scale-out fabric，而不是简单替代关系。[NVIDIA Spectrum-6](https://blogs.nvidia.com/blog/nvidia-spectrum-six-arrives-in-gigascale-ai-factories/)
2. 🔥 **IEEE P802.3dj 继续承担 200G/lane 到 1.6TbE 的标准化基线。** 该项目覆盖 200Gb/s、400Gb/s、800Gb/s、1.6Tb/s Ethernet；对 800G/1.6T 光模块而言，后续关注点仍是 200G/lane PAM4、FEC latency、optical PMD 与 electrical interface 收敛。[IEEE P802.3dj](https://www.ieee802.org/3/dj/index.html)
3. ⭐ **P802.3dj electrical ad hoc 资料仍是 200G/lane 电接口工程细节入口。** baseline proposal、SCMR、channel 与 comment resolution 资料显示，SerDes 速率提升后的瓶颈更多来自封装/连接器/板级通道闭环。[IEEE 802.3dj electrical](https://www.ieee802.org/3/dj/public/adhoc/electrical/index.html)
4. ⭐ **OIF CEI-448G-VSR/LR 已把 448G 分成 chip-to-module 与 backplane 两类接口问题。** 对下一代 3.2T/6.4T 光模块，VSR/LR 的 reach、材料、connector 与 compliance 会决定哪些架构能进入量产验证。[OIF current work](https://www.oiforum.com/technical-work/current-work/)
5. 📌 **以太网组织继续把 AI fabric 作为 2026 主线。** Ethernet Alliance 的 2026 Roadmap 强调 Ethernet 在 AI、cloud 与 next-gen connectivity 中的角色，说明 scale-out 网络仍会围绕开放互操作与高速信令演进。[Ethernet Roadmap](https://ethernetalliance.org/technology/ethernet-roadmap/)


## 🔦 光学与光模块

1. 🔥 **CPO、OCS 与 silicon photonics 的系统边界继续外扩。** Semiconductor Engineering 7 月 28 日文章认为 CPO 会从 scale-out 走向 rack 内 scale-up，OCS 可能补充甚至减少部分电交换层；这应视为产业观点，工程验证仍要看可维护性、激光、热和良率。[Semiconductor Engineering optics](https://semiengineering.com/all-ai-data-center-interconnects-will-be-optical-within-5-years/)
2. 🔥 **Marvell 1.6T optical DSP portfolio 已从单点 DSP 扩展到链路可靠性与安全。** Ara T、Ara X、Petra、Aquila M 分别覆盖 transmit-retimed optics、link reliability、gearbox、O-band coherent-lite/MACsec，采样时间为 Q1 2026。[Marvell 1.6T DSP](https://www.marvell.com/company/newsroom/marvell-1-6t-optical-dsp-ai-data-center-connectivity.html)
3. ⭐ **Spectrum-X Ethernet Photonics 把光互连收益表述为 fabric 级指标。** NVIDIA 宣称 Spectrum-X Ethernet Photonics 带来更高 power efficiency 与 MTBI 改善，提示 CPO/optical engine 的评价口径正在从 module watts 转向 job goodput 和运维稳定性。[NVIDIA Spectrum-6](https://blogs.nvidia.com/blog/nvidia-spectrum-six-arrives-in-gigascale-ai-factories/)
4. ⭐ **800G/1.6T 光模块需求仍由 AI data center 资本开支牵引。** 中际旭创赴港上市材料和媒体报道显示，募资用途集中在 optical interconnect R&D、全球产能与供应链韧性；市场反应波动不改变高速光模块作为 AI 基础设施“卖铲”环节的战略位置。[中际旭创官网](https://www.zj-innolight.com/en) / [Investing IPO](https://www.investing.com/news/stock-market-news/zhongji-innolight-slips-in-hong-kong-debut-after-68-bln-ipo-ai-jitters-weigh-4822331)
5. 📌 **1.6T 商用窗口继续并存 DSP、LPO/LRO 与 CPO 路线。** Marvell、Credo、OIF/OFC 2026 demo 均显示 retimed、linear、coherent-lite、CPO 会按 reach、power、telemetry、serviceability 分层落地。[Credo OFC 2026](https://www.stocktitan.net/news/CRDO/credo-to-showcase-optical-solutions-for-ai-scale-out-fabrics-at-ofc-2uywfnvc594q.html)


## 🖥️ AI服务器与超节点

1. 🔥 **NVLink 6 把 scale-up fabric 评价从带宽转向 tokens/watt。** NVIDIA 技术博客称 Vera Rubin NVL72 单 rack 提供 260 TB/s aggregate bandwidth、130 TFLOPS in-network compute，并把 scale-up 域扩展路线与 CPO 连接起来。[NVIDIA NVLink 6](https://developer.nvidia.com/blog/nvidia-nvlink-the-scale-up-network-for-ai-factories/)
2. 🔥 **Spectrum-6 与 ConnectX-9 组成下一代 Spectrum-X Ethernet。** 该组合服务 scale-out fabric，NVIDIA 将其放入 Vera CPU、Rubin GPU、NVLink 6 Switch、BlueField-4 DPU 的系统级平台中，说明 AI 服务器互连正在变成 rack/platform co-design 问题。[NVIDIA Spectrum-6](https://blogs.nvidia.com/blog/nvidia-spectrum-six-arrives-in-gigascale-ai-factories/)
3. ⭐ **SK Group/NVIDIA 大型 AI 基础设施合作强化“AI factory + memory + power”一体化趋势。** 媒体报道提到 SK Telecom 规划韩国 2GW AI data center，并使用 NVIDIA DSX、Vera Rubin 与 HBM4 相关平台；具体部署规模仍以官方后续披露为准。[Tom's Hardware SK/NVIDIA](https://www.tomshardware.com/tech-industry/artificial-intelligence/nvidia-and-sk-group-enter-usd500-billion-ai-partnership-plan-to-supercharge-ai-infrastructure-with-next-gen-memory-and-massive-ai-factories)
4. ⭐ **UALink 2.0 与 UEC 1.x 仍是开放互连生态的比较基线。** UALink 面向 scale-up，UEC 面向 scale-out Ethernet；后续关键是 collectives、telemetry、congestion control 与故障恢复能否进入实际系统验证。[UALink specs](https://ualinkconsortium.org/specification/) / [UEC](https://ultraethernet.org/)
5. 📌 **大模型 MoE 与 disaggregated serving 正在驱动 fabric 分层。** scale-up 关注 GPU-to-GPU latency、all-to-all 与 in-network reductions；scale-out 关注 100k+ GPU 域的拥塞、路径选择和 failure recovery。[NVIDIA NVLink 6](https://developer.nvidia.com/blog/nvidia-nvlink-the-scale-up-network-for-ai-factories/)


## 🏢 计算中心与基础设施

1. 🔥 **液冷从选配进入 power-constrained facility planning。** Schneider Electric 7 月 28 日文章称 direct-to-chip liquid cooling 常见 PUE 区间约 1.10-1.20，并可在适用场景降低 cooling energy；这意味着互连功耗、交换机功耗和冷却预算需要一起建模。[Schneider liquid cooling](https://blog.se.com/datacenter/2026/07/28/data-center-power-density-planning-liquid-cooled-ai-data-centers-around-grid-and-power-constraints/)
2. 🔥 **AI data center 正从电力消费者变成 grid stakeholder。** CoreSite 2026 outlook 引述行业观点：运营商会共同投资电网升级、部署 on-site power generation/storage，并把地理位置、电价和冷却能力作为选址变量。[CoreSite 2026 outlook](https://www.coresite.com/blog/data-center-outlook-2026-power-and-cooling-challenges-and-solutions-are-top-of-mind)
3. ⭐ **AI infrastructure provider 财报继续显示基础设施链条未降温。** Barron's 报道 Schneider Electric、Solstice Advanced Materials、Quanta Services 等基础设施供应商上调或强于预期，说明资本市场虽担心 AI 过热，电力/冷却/建设链条仍处于投入周期。[Barron's infrastructure](https://www.barrons.com/articles/ai-infrastructure-spending-10fcdde3)
4. ⭐ **高密度存储也在挤压机房功率和网络规划。** WEKA 的 WEKApod 3 把 AI storage density、NVMe fabric 与供电约束放在同一问题中；训练/推理集群不是只有 GPU 交换网络，存储侧也会要求更高吞吐和更短路径。[TechRadar WEKA](https://www.techradar.com/pro/wekas-new-pod-claims-1000pb-in-a-56u-rack-using-1-800-micron-245-76tb-ssds-and-a-decades-old-compression-trick)
5. 📌 **OCP 仍是设施、冷却、网络开放协作的重要跟踪入口。** Korea Tech Day 和 OCP Educational Webinar Program 持续覆盖 AI data center、high-radix switching、open standards 与 optical interconnect 主题。[OCP webinars](https://www.opencompute.org/summit/ocp-educational-webinar-program)
