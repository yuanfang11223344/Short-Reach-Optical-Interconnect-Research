3. ⭐ **Tom’s Hardware 转述 CIC/元杰半导体 IPO 文件称 data center optical interconnect 市场 2030 年可能达 144.4B 美元。** 该报道强调 silicon photonics、CPO 和 1.6T/3.2T 是主要增长轴；这是第三方/申报材料预测，适合做趋势参考，不应作为确定性市场结论。https://www.tomshardware.com/tech-industry/photonics/ai-data-center-optical-interconnect-market-to-hit-usd144-billion-by-2030-an-over-ten-fold-increase-from-2024-figures-according-to-new-projections-silicon-photonics-expected-to-account-for-nearly-two-thirds-of-revenue-driven-by-co-packaged-optics
4. ⭐ **Lumentum 产业报道显示 200G-per-lane、1.6T transceivers、OCS、NPO/CPO 和高功率激光源正在同时升温。** 报道称 Lumentum Q4 FY2026 开始初始 1.6T transceiver 出货，并获得 external laser source modules for CPO 初始订单；具体客户和量产节奏仍以公司正式披露为准。https://convergedigest.com/lumentum-ai-scale-up-optics-data-center/

## 📄 论文速递

1. 🔥 **arXiv:2608.03146 — Zero-change foundry compatible silicon photonics MEMS optical switch。** 论文报告 C-band broadband MEMS switch、超过 30 dB extinction ratio、低于 1.5 dB insertion loss 和约 20 nW static power，指向可制造 OCS 基础器件；工程化仍需可靠性、阵列规模和封装验证。https://arxiv.org/abs/2608.03146
2. 🔥 **HotI 2026 paper: “The Multipath Reliable Connection (MRC) Transport”。** 该题目指向 AI fabric 可靠传输、多路径和拥塞控制的重构，适合与 UEC/UET、RoCE 演进和大规模 collective communication 一起跟踪。https://hoti.org/2026/program.html
3. ⭐ **HotI 2026 paper: “Demystifying NVSHMEM: A System-Level Analysis on Symmetric Memory and Device-Initiated Operations in GPU Communication”。** 这类系统分析能帮助判断 GPU 通信库是否真正吃满底层 NVLink/InfiniBand/Ethernet 能力。https://hoti.org/2026/program.html
4. ⭐ **HotI 2026 paper: “From Datacenter to Wide Area: Scale-Across Federated Learning on Real Long-Haul RDMA”。** 题目把 long-haul RDMA 与 federated learning 联系起来，值得观察 scale-across 场景中光传输、RDMA 和应用调度如何共同约束。https://hoti.org/2026/program.html
