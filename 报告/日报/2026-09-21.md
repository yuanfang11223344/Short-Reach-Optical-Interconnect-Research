## 🔌 SerDes与互连技术

1. 🔥 **ECOC Exhibition 2026 今日在 Malaga 开展，OIF 的 448G/224G CEI 与 CMIS/CPO/NPO 互操作进入现场验证窗口。** ECOC 官方页面显示展会日期为 2026-09-21 至 2026-09-23，会议为 2026-09-20 至 2026-09-24；OIF 会前材料把 live demo 范围放在 448G and 224G Common Electrical I/O、CMIS、Co-Packaging、Energy Efficient Interfaces 等方向。后续判断重点应放在 host、module、test equipment、FEC、BER、link training、management state 和 thermal telemetry 的公开证据，而不是只看 lane rate。https://www.ecocexhibition.com/  https://www.oiforum.com/meetings-events/oif-ecoc-2026/
2. 🔥 **OIF 首页把 1600ZR、800G coherent、CEI-224G、CMIS 与 EEI 同时列为 hot topics，说明 AI-era interconnect 正在被 coherent DCI、short-reach electrical I/O、module management 与 energy efficiency 共同定义。** 对 SerDes 团队而言，CEI-224G 的价值不只在速率，也在 reach class、package/channel loss、test methodology 与互操作生态是否能收敛。https://www.oiforum.com/
3. ⭐ **Astera Labs 的 400G-per-lane 文章继续把 copper 与 optical 的边界放到 rack-scale 系统架构中讨论。** 官方博客讨论 retimer、active electrical cable、linear pluggable optics 与 co-packaged optics 在距离、功耗、可维护性和部署复杂度上的取舍；这类分层视角适合用于评估 400G/lane 之后哪些链路仍适合铜、哪些应转向 optics。https://www.asteralabs.com/resources/blog/the-400g-per-lane-inflection-point-where-copper-and-optical-meet-in-ai-infrastructure/
4. ⭐ **UALink 与 Ultra Ethernet Consortium 继续提供 scale-up / scale-out 的开放参照系。** UALink 官网强调面向 accelerator-to-accelerator 的开放、低延迟互连；UEC 官网显示其参加 2026-09-15 至 2026-09-17 的 AI Infra Summit，并说明 compliant Ethernet equipment 的开放生态路线。AI 超节点需要同时跟踪 rack 内 accelerator fabric 与 rack 间 Ethernet stack。https://ualinkconsortium.org/  https://ultraethernet.org/

## 📄 论文速递

1. 🔥 **arXiv:2609.20686 - "Volumetric Evanescent Edge Coupling for Fiber-to-Chip Optical I/O"。** 论文提出 volumetric edge coupling，把 fiber-to-chip optical I/O 从 chip facet 单行通道扩展到二维区域；摘要称 1550 nm 仿真峰值耦合效率 88%（-0.56 dB）和 86.45 nm 1-dB bandwidth，适合作为 high-density CPO/optical I/O 封装线索。https://arxiv.org/abs/2609.20686
2. 🔥 **arXiv:2609.01821 - "Scaling Inference Prefill with High-Radix Photonic Interconnects"。** 论文建模比较 copper-based GPU systems 与 high-bandwidth integrated photonics，在 LLM inference prefill 的通信受限阶段讨论 high-radix photonic interconnect 的潜在收益；它是 workload-level 建模证据，不是实机部署评测。https://arxiv.org/abs/2609.01821
3. ⭐ **arXiv:2607.27187 - "A Photonic-CXL Memory Appliance for Scalable KV Cache Management in LLM Inference"。** 论文提出 Photonic-CXL hybrid memory appliance，以 passive fiber shuffle 替代电交换实现 16 hosts / 32 TB shared memory 的 switch-free full crossbar；摘要报告相对 electrical CXL pools 的 latency 和 TTFT 改善，是 Photonic Fabric 与 CXL memory pooling 结合的代表性研究。https://arxiv.org/abs/2607.27187
4. ⭐ **arXiv:2609.09400 - "QPS-ToR: A Parallel Iterative Switching Algorithm for Reconfigurable Optical Datacenter Switching"。** 论文聚焦 reconfigurable optical datacenter network 的 ToR scheduling，提醒 optical circuit switching 的瓶颈同样在 scheduling/control plane，而不只在光器件。https://arxiv.org/abs/2609.09400
5. 📌 **arXiv:2609.11649 - "Grid-to-Chip: End-to-End Power Solutions for Scalable AI Data Centers"。** 论文把 medium-voltage interface、higher-voltage DC distribution、solid-state transformers、wide-bandgap devices、chip-level power delivery、liquid cooling 与 grid stability 放在同一个 AI data center 框架；适合作为互连路线做 power/cooling 边界检查的依据。https://arxiv.org/abs/2609.11649
