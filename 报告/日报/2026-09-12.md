## 🔌 SerDes与互连技术

1. 🔥 **OIF 的 1600ZR、CEI-224G/448G、EEI 和 CMIS-LT 线索继续成为 9 月下半月互操作观察主线。** 对 AI 基础设施而言，重点不是单点速率宣传，而是 coherent DCI、200G/lane electrical、linear/retimed electrical interface 与 module management 能否在 ECOC 窗口形成可复用组合。https://www.oiforum.com/technical-work/implementation-agreements-ias/
2. 🔥 **OIF Energy Efficient Interfaces 仍是 200G/lane 时代的功耗约束入口。** LPO、LRO、RTLR、NPO 与 CPO 都在尝试减少 DSP、retimer 或光电转换带来的能耗与延迟，短期更可能是多路线并存，而不是某一种封装形态突然胜出。https://www.oiforum.com/technical-work/hot-topics/energy-efficient-interfaces/
3. ⭐ **Ethernet Alliance 的 ECOC 2026 公开入口继续指向 400G/800G/1.6T Ethernet 互操作。** 对训练和推理集群，真正值得跟踪的是 link training、FEC、OSFP/OSFP-XD、测试仪表和多厂商模块的一致性，而不是只看单家 demo。https://ethernetalliance.org/events/
4. ⭐ **UALink 与 UEC 继续把 scale-up 和 scale-out 分成两条开放互连路线。** UALink 更贴近 accelerator-to-accelerator fabric，UEC 更贴近 AI Ethernet；两者与 NVLink Fusion 的关系会决定开放集群是否能在软件栈、遥测和拥塞控制上追上专有方案。https://ualinkconsortium.org/

## 🔦 光学与光模块

1. 🔥 **Ayar Labs 2026 年 CPO 融资扩展到 6.5 亿美元，资本信号仍然强于量产证据。** 这说明业界继续押注 chip-to-chip optical I/O 和 beyond-the-rack scale-up，但公开资料没有给出客户量产规模或独立系统评测，当前应归类为 manufacturing readiness 与生态建设信号。https://ayarlabs.com/news/ayar-labs-expands-2026-funding-to-650-million/
2. 🔥 **ECOC Exhibition Market Focus 把 CPO/OCI、NPO、OCS、1.6T/更高速 Ethernet 和 AI photonics 放在同一议程。** 9 月 21-23 日的公开材料将是验证 2026 年下半年路线图的核心来源，尤其要看样品、互操作矩阵、功耗披露和测试条件。https://www.ecocexhibition.com/visit/market-focus/market-focus-session-information/
3. ⭐ **Lumentum 的 AI data center 光学路线继续覆盖 datacom laser、ELS、CPO laser、NPO 和高速 transceiver。** 对本专题，最关键问题是 laser source、外部光源、模块热管理和封装良率能否配合 rack-scale 节奏；暂无独立评测证明所有路线已进入同一成熟度。https://www.lumentum.com/en
4. 📌 **Ciena Vesta / WaveLogic coherent 叙事适合放在 scale-across，而不是 rack 内互连。** 6.4T-class coherent optics 的价值主要在 DCI、campus 与 metro AI cloud provider 网络；它解决的是跨机房容量与频谱效率，不直接替代 GPU box 内的电互连。https://www.ciena.com/products/vesta

## 🖥️ AI服务器与超节点

1. 🔥 **d-Matrix 接入 NVIDIA NVLink Fusion/MGX 的路线继续强化 inference rack 竞争。** Raptor XPU 的公开叙事强调 ultra-low latency token service，这把 decode-heavy 推理从“单卡算力”拉回到 memory access、fabric latency 与 rack integration；暂无独立第三方系统评测。https://blogs.nvidia.com/blog/d-matrix-nvlink-fusion/
2. 🔥 **Qualcomm/Amazon 多代 AI data center collaboration 把 custom silicon、optical connectivity 与 Amazon network interconnect 放在同一框架。** 公开信息没有披露端口拓扑、SerDes 代际、客户部署规模或量产节奏，但它说明 hyperscaler 对“芯片 + 光电互连 + 网络软件”共同设计的需求在上升。https://investor.qualcomm.com/news-events/press-releases/news-details/2026/Qualcomm-Announces-Multi-Generational-Product-Collaboration-with-Amazon-to-Build-Next-Generation-AI-Data-Center-Infrastructure/default.aspx
3. ⭐ **NVIDIA NVLink Fusion 继续把第三方 accelerator 带入 rack-scale fabric 叙事。** 这对生态的影响大于单次合作：如果 memory semantics、collectives 和管理面能复用，推理专用芯片才更容易进入既有 AI factory。https://www.nvidia.com/en-us/data-center/nvlink-fusion/
4. 📌 **Supermicro Blackwell Ultra / GB300 rack-scale 系统仍是整柜工程化的公开观察入口。** 重点看 NVLink domain、network fabric、液冷、电源、服务性与交付周期；单个服务器 SKU 不足以证明完整 supernode 的可复制部署能力。https://www.supermicro.com/en/accelerators/nvidia

## 🏢 计算中心与基础设施

1. 🔥 **AI Infra Summit 2026 将在 9 月 15-17 日集中讨论 compute、data movement、AI data centers、power/cooling 和 physical AI。** 它紧接在今日之后，是观察 UEC/UALink、optics、storage fabric、liquid cooling 和 rack-scale deployment 的最近公开窗口。https://www.ai-infra-summit.com/
2. ⭐ **UEC 在 AI Infra Summit 的活动入口继续把 AI Ethernet 放到产业验证场。** 未来几周要关注 congestion control、telemetry、packet spraying、lossless/lossy trade-off 和故障收敛，而不只是端口速率。https://ultraethernet.org/event/uec-at-ai-infra-summit-2026/
3. ⭐ **Nokia 的 AI cloud provider 网络叙事强调 optical、IP routing 和 datacenter switching 的组合。** 这提醒我们 GPU utilization 受跨机房光传输、IP/optical convergence、自动化运营和故障域影响，不只取决于 rack 内互连。https://www.nokia.com/networks/solutions/ai-cloud-provider/
4. 📌 **OCP Global Summit 2026 是 10 月检验开放机架、电源、散热、硬件管理与 AI server serviceability 的关键节点。** 如果 9 月出现更多整柜 AI 系统，OCP 会提供更开放的工程复用视角。https://www.opencompute.org/summit/global-summit

## 📄 论文速递

1. 🔥 **arXiv:2609.01821 - "Scaling Inference Prefill with High-Radix Photonic Interconnects"。** 论文把 3D-integrated silicon photonics 与 MoE prefill、长上下文和高 batch 推理联系起来，报告 2.1-3.2x latency improvements；这是建模/模拟证据，不等同于实机部署结果。https://arxiv.org/abs/2609.01821
2. 🔥 **arXiv:2605.21187 - "High-speed Networking for Giga-Scale AI Factories"。** 论文讨论 Spectrum-X multiplane architecture、硬件加速 load balancing、jitter/latency 和 link failure 表现，是理解 AI Ethernet scale-out 的系统论文参照。https://arxiv.org/abs/2605.21187
3. ⭐ **arXiv:2603.07373 - "Scheduling Parallel Optical Circuit Switches for AI Training"。** Spectra 面向 parallel OCS 和 AI traffic demand matrix 设计调度方法，适合与实际 OCS 交换机、MEMS switch 和作业调度系统做横向比较。https://arxiv.org/abs/2603.07373
4. ⭐ **arXiv:2602.12521 - "Opus: Photonic Rail-Optimized Fabric in ML Datacenters"。** Opus 强调 parallelism-driven rail reconfiguration，把 OCS 从静态拓扑配置推进到训练阶段感知调度，是理解 optical fabric 软件化的重要样本。https://arxiv.org/abs/2602.12521
5. 📌 **arXiv:2504.09892 - "Vermilion: A Traffic-Aware Reconfigurable Optical Interconnect with Formal Throughput Guarantees"。** 该工作提供 traffic-aware reconfigurable optical interconnect 的形式化吞吐保证视角，可补足产业 demo 常缺的理论边界。https://arxiv.org/abs/2504.09892
