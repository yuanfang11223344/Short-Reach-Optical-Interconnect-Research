## 🔌 SerDes与互连技术

1. 🔥 **AI Infra Summit 第二天把 data movement 议题直接推进到 224/448Gbps copper and optics、compute/memory connectivity 与 AI memory wall。** 官方日程中，Data Movement Track 包含 “Fast Islands, Slow Inference: Every Compute Choice Is a Network Decision”“Scaling the AI Factory with Compute and Memory Connectivity”“Scaling the AI Memory Wall”等 session，说明 AI cluster 互连讨论正在从单端口速率扩展到 inference serving、内存层次和系统拓扑。https://www.ai-infra-summit.com/2026agenda
2. 🔥 **Samtec 在 AI Infra Summit data movement track 讨论 “224/448 Gbps Copper and Optics: Can I Have Both?”。** 这个标题本身很有代表性：224G/448G 时代不是铜缆或光链路二选一，而是要按 reach、功耗、serviceability、link margin、rack topology 做混合取舍。https://www.ai-infra-summit.com/2026agenda
3. ⭐ **Astera Labs Taurus 3.2T Smart Retimers/Smart Redrivers 继续把 OCP Signal Conditioner Standard Footprint 推向 AI scale-up/scale-out 互连。** 官方公告称该 footprint 支持在高 reach retimer 与低功耗 redriver 之间迁移，重点是避免板级重设计；对 224G/3.2T 平台，信号调理器正在成为系统灵活性部件，而不仅是“补损耗”的器件。https://www.asteralabs.com/news/astera-labs-expands-taurus-family-with-industrys-first-ocp-standard-footprint-compatible-3-2t-smart-retimers-and-smart-redrivers/
4. ⭐ **UALink 近期博客把下一阶段路线写成 400G data-rate、optical interconnects、end-to-end resiliency 和 richer management。** 这说明开放 scale-up fabric 的验证焦点正在从 UALink 1.0/2.0 的链路速率，转向更长 reach、链路健康管理、故障恢复和可观测性。https://ualinkconsortium.org/category/blog/

## 🔦 光学与光模块

1. 🔥 **OIF/ECOC 2026 互操作预告继续是本周最重要的光互连锚点：448G/224G electrical、coherent optical systems、CMIS、CPO/NPO 与 EEI 被放进同一套 AI-era interoperability 展示。** 其价值不在于单个 headline 速率，而在于跨厂商测试、模块管理、仪表一致性和高密度系统可维护性。https://www.oiforum.com/oif-validates-ai-era-interoperability-live-at-ecoc-2026-through-multi-vendor-demonstrations-and-expert-sessions/
2. 🔥 **Marvell 在 AI Infra Summit 展示 Photonic Fabric、RELIANT Interconnect Telemetry Platform 与 Teralynx T100 102 Tbps Ethernet switch。** 官方材料将 Photonic Fabric 定位为跨多机架 memory sharing，把 RELIANT 定位为 optical/electrical links 的实时健康和性能可见性；这条叙事把 optics、switching、CXL/memory pooling 与运维 telemetry 接到一起。https://investor.marvell.com/news-events/press-releases/detail/1032/marvell-to-showcase-end-to-end-ai-data-center-connectivity-portfolio-at-ai-infra-summit-2026
3. ⭐ **OpenLight 今年已披露 3.2T DR8 silicon photonics PIC 原型采样和 1.6T DR8 LRO/LPO qualification samples 订单。** 这类 PIC/optical engine 进展适合作为 1.6T 到 3.2T 光模块路线的技术素材，但日报仍按“采样/qualification”表述，不外推为规模量产。https://openlightphotonics.com/newsroom/openlight-introduces-3-2t-dr8-silicon-photonics-pics-as-well-as-1-6t-dr8-lro-and-lpo-variants
4. 📌 **OCP Short Reach Optical Interconnect 社区使命强调 processor-to-processor 与 processor-to-memory bandwidth 的短距光 I/O 需求与指标。** 这与今天 AI Infra Summit 的 compute/memory connectivity 议题同频：光互连正在从 switch-to-switch、module-to-module 进一步靠近 accelerator 和 memory boundary。https://www.opencompute.org/community/short-reach-optical-interconnect

## 🖥️ AI服务器与超节点

2. 🔥 **Marvell 的展示清单把 scale-up、scale-out、scale-across 作为同一 AI data center connectivity portfolio。** 对超节点而言，这意味着 intra-rack accelerator fabric、rack-to-rack Ethernet、CXL/Photonic Fabric memory appliance 和 telemetry 不再是独立子系统，而会共同影响 token efficiency、failure isolation 和 capacity utilization。https://investor.marvell.com/news-events/press-releases/detail/1032/marvell-to-showcase-end-to-end-ai-data-center-connectivity-portfolio-at-ai-infra-summit-2026
3. ⭐ **Astera 在 AI Infra Summit 议程中围绕 “Scaling the AI Factory with Compute and Memory Connectivity” 发声。** 结合 Taurus 3.2T retimer/redriver 与 Scorpio/CXL 产品线，该公司正在把 PCIe/CXL/Ethernet signal conditioning 与 memory connectivity 打包成 AI factory 连接层；暂无独立系统评测。https://www.ai-infra-summit.com/2026agenda
4. 📌 **d-Matrix、Marvell、Nebius、Mirantis 出现在 distributed AI orchestration panel。** 第三方 XPU/AI accelerator 要进入 rack-scale 平台，关键验证点仍是 collective communication、network semantics、software orchestration、link telemetry 和可维护性；本日报不写未公开客户或量产时间。https://www.ai-infra-summit.com/2026agenda

## 📄 论文速递

1. 🔥 **arXiv:2609.11649 - "From Grid to Chip: Power Architecture, Stability, and Flexibility of AI Data Centers"。** 论文把 AI data centers 定义为 grid-interactive computing systems，覆盖 medium-voltage interface、higher-voltage DC distribution、solid-state transformers、wide-bandgap devices、chip-level power delivery、liquid cooling 和 rack/facility/grid 三层 stability；适合作为互连拓扑的电力边界条件。https://arxiv.org/abs/2609.11649
2. 🔥 **arXiv:2609.04025 - "THz-SynC: Collective Synthesis with Contextual-Bandit-Assisted Coordination for Reconfigurable Hybrid Optical-THz AI Datacenters"。** 论文把 THz rack-to-rack wireless interconnect 作为 optical fabric 的补充，针对 All-to-All/AllReduce 做 collective-aware routing 与 delay-energy tradeoff；这是 trace-driven evaluation，不等同真实部署。https://arxiv.org/abs/2609.04025
3. ⭐ **arXiv:2609.03125 - "A Time-Encoded Analog Photonic Interposer for Energy-Efficient Integration of Analog Vision Sensors and Analog Accelerators"。** 论文使用 time-encoded analog photonic interposer 和 WDM link 在 chiplets 之间传输模拟信号，强调绕开高精度 ADC/DAC pipeline；它更偏 analog sensor/accelerator integration，不能直接外推到大模型 GPU fabric。https://arxiv.org/abs/2609.03125
4. ⭐ **arXiv:2608.11639 - "Towards Terabit/$λ$/s Multidimensional Silicon Photonic Engine"。** 论文展示 multidimensional silicon photonic engine，把空间/偏振复用、光信号处理与单芯片集成联系到高容量低延迟 inter-chip communication；对 CPO/optical engine 的启发是 channel parallelism 和 DSP power 可能成为同等重要约束。https://arxiv.org/abs/2608.11639
5. 📌 **arXiv:2607.27187 - "A Photonic-CXL Memory Appliance for Scalable KV Cache Management in LLM Inference"。** 论文提出 photonic-CXL hybrid memory appliance，用被动 fiber shuffle 替代 electrical switches，面向 KV cache 的 TB-scale shared memory；其模拟结果展示 TTFT 改善，但仍需区分 architecture paper 与商用系统交付。https://arxiv.org/abs/2607.27187
